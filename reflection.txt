Reflecting on the Liftoff Clone build, the hardest part was managing the complex state of the active workout logger. Allowing users to dynamically add sets, copy weights/reps from previous sets, mark them completed via swipe with haptic feedback, and trigger a floating auto-start timer required careful orchestration of Riverpod's Notifier state so that the UI re-rendered smoothly without losing user input in text fields. The easiest part was the Firebase integration; having built local-first to cloud-scalable apps before, establishing the mock repositories and hot-swapping them to Firestore interfaces was seamless. If I had more time, I would improve the social features by adding the ability to tap on users in the leaderboard to view their routines and give them 'kudos', adding a deeper layer of community engagement.
